Alata brings routing, databases, background jobs, and scheduling into one application. Built on FastAPI, SQLAlchemy, and taskiq, it gives your project a consistent structure from its first route to production.

## Create a project

Generate a new application with Python 3.12+ and [uv](https://docs.astral.sh/uv/):

```bash title="Terminal"
uvx --from git+ssh://git@github.com/JoBinsJP/alata-core.git@v0.12.0.0 \
  alata-new new my-app
cd my-app
```

The [installation guide](/docs/getting-started/installation#point-the-project-at-the-framework) walks you through connecting the framework, configuring your database, and starting the server. Repository access is required to install Alata over SSH.
